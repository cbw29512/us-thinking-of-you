# Us — Thinking of You

A simple, touch-friendly web app for couples and close friends.

## Features
- Big heart button with animation and haptic feedback
- Mood check (one tap)
- Async Rock Paper Scissors
- Pairing via 5-digit code (client-side demo)
- Local persistence

## Deploy to Netlify
1. Push this folder to a GitHub repository
2. In Netlify: New site from Git → select the repo
3. Publish directory: `.` (root)
4. No build command

## Local
Open `index.html` in a browser, or:
```bash
npx serve .
```

Haptics work best on Android Chrome. iOS support is limited in the browser.
